Warehouse App is a simple desktop application written in Python using the Tkinter library.
The application is designed for basic warehouse management and allows users to work with warehouse data through a graphical user interface (GUI).

This project was created to practice Python programming, GUI development, and application logic outside of the console environment.

Features

Graphical user interface built with Tkinter

Basic warehouse data management

User interaction through buttons and input fields

Clear and structured application logic
